# 断网重连机制

- 在网络切换时，各个channel的socket连接会断开，相关线程对象会回收。
- 由于mcThreadProc_isCli线程一直在不停的循环执行，当网络再次连接后，会执行startChannel函数，再次启动talk通道，并启动相关IO线程。
- 在启动talk通道时，会再次和服务器建立连接，并执行登录操作。
- **<font color=#ff0000 size=3>talk通道连接成功后，稍后会收到服务器发来的音视频媒体流(约5秒)。</font>**
- talk通道将媒体流数据转到mgr线程，然后分别发送到对应的数据队列。
- mcThreadProc_mis_media和mcThreadProc_mis_realTimeMedia线程分别从队列李拿到数据后，再次执行会执行startChannel函数启动自己的IO线程。
